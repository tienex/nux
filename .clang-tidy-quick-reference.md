# clang-tidy Quick Reference for NUX Kernel

## Quick Commands

```bash
# Check modified files only
./scripts/quick-tidy.sh

# Fix modified files
./scripts/quick-tidy.sh --fix

# Check entire codebase
./scripts/run-clang-tidy.sh

# Fix entire codebase
./scripts/run-clang-tidy.sh . --fix

# Check single file
clang-tidy path/to/file.c -- -I.

# Fix single file
clang-tidy path/to/file.c --fix --fix-errors -- -I.
```

## Enabled Check Categories

| Category | Description | Auto-fixable |
|----------|-------------|--------------|
| `bugprone-*` | Detects bug-prone code patterns | Some |
| `clang-analyzer-*` | Deep static analysis | No |
| `concurrency-*` | Thread safety issues | Some |
| `misc-*` | Miscellaneous checks | Some |
| `performance-*` | Performance improvements | Some |
| `portability-*` | Cross-platform issues | Some |
| `readability-*` | Code readability and naming | Most |

## Common Warnings

### Naming Conventions

**Warning:** `invalid case style for function 'my_function'`
- **Fix:** Rename to PascalCase: `MyFunction`
- **Auto-fixable:** Yes

**Warning:** `invalid case style for macro definition 'my_macro'`
- **Fix:** Rename to UPPER_CASE: `MY_MACRO`
- **Auto-fixable:** Yes

### Bug Detection

**Warning:** `an assignment within an 'if' condition is bug-prone`
```c
// Bad
if (x = GetValue()) { }

// Good
x = GetValue();
if (x) { }
```
- **Auto-fixable:** No

**Warning:** `potential null pointer dereference`
```c
// Bad
void Func(int *Ptr) {
    *Ptr = 5;  // No NULL check
}

// Good
void Func(int *Ptr) {
    if (Ptr == NULL) return;
    *Ptr = 5;
}
```
- **Auto-fixable:** No

### Readability

**Warning:** `function 'FunctionName' exceeds recommended size/complexity`
- **Fix:** Refactor into smaller functions
- **Auto-fixable:** No

**Warning:** `magic number 42 should be replaced with a named constant`
```c
// Bad
if (Size > 42) { }

// Good
#define MAX_SIZE 42
if (Size > MAX_SIZE) { }
```
- **Auto-fixable:** No

### Performance

**Warning:** `parameter 'Param' is passed by value and only used as const reference`
```c
// Bad
void Func(LARGE_STRUCT Param) {
    Use(&Param);
}

// Good
void Func(CONST LARGE_STRUCT *Param) {
    Use(Param);
}
```
- **Auto-fixable:** No

## Naming Convention Summary

| Type | Convention | Example |
|------|------------|---------|
| Functions | PascalCase | `CpuInitialize` |
| Macros | UPPER_CASE | `MAX_VALUE` |
| Types | PascalCase/UPPER_CASE | `CPU_INFO`, `UINT32` |
| Global vars | gPascalCase | `gNumberCpus` |
| Static vars | sPascalCase/gPascalCase | `sCpuCount` |
| Local vars | PascalCase/camelCase | `CpuInfo`, `index` |
| Parameters | PascalCase | `PhysId` |
| Constants | UPPER_CASE | `PAGE_SIZE` |

## Disabling Checks

### For entire file
```c
// At top of file
// NOLINTBEGIN
... code ...
// NOLINTEND
```

### For specific lines
```c
int value = 42;  // NOLINT(readability-magic-numbers)
```

### For specific check
```c
// NOLINTNEXTLINE(bugprone-assignment-in-if-condition)
if (x = GetValue()) {
    ...
}
```

## Integration with Git

### Pre-commit hook
Create `.git/hooks/pre-commit`:
```bash
#!/bin/bash
./scripts/quick-tidy.sh
if [ $? -ne 0 ]; then
    echo "clang-tidy checks failed. Fix issues or use --fix"
    exit 1
fi
```

### CI/CD integration
```yaml
- name: Run clang-tidy
  run: ./scripts/run-clang-tidy.sh
```

## Troubleshooting

**Problem:** "compilation database not found"
- **Solution:** Use `-- -I.` to pass compilation flags manually

**Problem:** Too many false positives
- **Solution:** Add exceptions to `.clang-tidy` CheckOptions

**Problem:** Auto-fix breaks code
- **Solution:** Review changes carefully; some fixes need manual intervention

**Problem:** Checks take too long
- **Solution:** Use `./scripts/quick-tidy.sh` to check only modified files
